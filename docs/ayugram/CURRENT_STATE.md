## 2. Сборочное окружение

* **Платформа**: Windows 11 / Windows 10 (x64).
* **Сборочная структура**:

  - Скрипт генерации решения: `tdesktop/Telegram/configure.bat x64 ...`

## 3. Что уже реализовано в AyuGram

В кодовой базе (`tdesktop/Telegram/SourceFiles/ayu/`) активны следующие возможности:

1. **Ghost Mode (Фантомный режим)**:
   - Не отправлять статус прочтения входящих сообщений.
   - Не отправлять статус прочтения историй (Stories).
   - Не отправлять статус набора текста ("печатает...").
   - Скрытие статуса онлайн при отправке сообщений (отложенная отправка или маскировка).
2. **Локальная история сообщений (Message History & Anti-Recall)**:
   - Сохранение удалённых собеседником сообщений в локальную базу данных SQLite (`ayu_database.cpp`).
   - Сохранение истории редактирования сообщений с отображением старых ревизий.
   - Визуальные метки для удалённых и отредактированных сообщений.
3. **Streamer Mode (Режим стримера)**:
   - Маскировка номеров телефонов, личных данных и ID пользователей на экране.
4. **Local Telegram Premium**:
   - Эмуляция клиентских Premium-функций (удвоенные лимиты в UI, эмодзи-статусы локально).
5. **Встроенный переводчик**:
   - Поддержка нескольких провайдеров перевода текста чатов.
6. **Кастомизация UI**:
   - Пользовательские шрифты, кастомные иконки, темы, гибкие фильтры сообщений.

## 4. Известные особенности и ограничения

* **Android-версия**: Репозиторий `AyuGram4A` не полностью открыт (приватный подмодуль `AyuGram4A_proprietary`), поэтому разработка ведется исключительно на базе открытого Desktop-клиента.
* **Сложность сборки полного дистрибутива**: Сборка WebRTC (`libtg_owt`) и Qt с нуля требует значительного времени процессора и десятков гигабайт сборочных артефактов; для локальной работы рекомендуется инкрементальная сборка только необходимых модулей через CMake.

## 5. Выполненные и текущие задачи

1. **[Реализовано] Оптимизация контекста для AI-ассистентов (Codex / Antigravity)**:
   - Создана модульная документация в папке `docs/` (`ARCHITECTURE.md`, `CURRENT_STATE.md`, `DECISIONS.md`).
   - Файл `AGENTS.md` сокращен с 853 строк до 65 строк высокосигнальных инструкций, устранены устаревшие данные (фиктивный ai-tdesktop, чужие пути WSL).
   - Настроены проектные конфигурации `.codex/config.toml` (увеличен `model_auto_compact_token_limit` до 180 000 токенов для исключения раннего сжатия).

2. **[Реализовано] Функция очистки папок диалогов от архивных чатов**:
   - Добавлен модуль `ayu/features/folders/ayu_folders_cleaner.h / .cpp`.
   - Внедрена клиентская опция `AyuSettings::excludeArchivedFromFolders` с динамической фильтрацией в `ChatFilter::contains`.
   - Добавлена кнопка глобальной очистки облачных папок в `Настройки AyuGram -> Внешний вид -> Папки чатов` с диалоговым окном подтверждения.
   - Добавлены контекстные пункты в меню вкладок папок на боковой панели: «Очистить от архивных чатов» для конкретной папки и для всех папок сразу.

3. **[Реализовано] Полное снятие лимита на количество аккаунтов (Unlimited Accounts)**:
   - Лимит `kMaxAccounts` и `kPremiumMaxAccounts` в `Main::Domain` увеличен со 100/200 до 10 000.
   - `Domain::maxAccounts()` возвращает `kPremiumMaxAccounts` безусловно, снимая искусственную привязку к наличию Telegram Premium.
   - Локальное хранилище аккаунтов (`storage_domain.cpp`) и проверка диалога ограничений (`core/application.cpp`, `settings_information.cpp`) поддерживают расширенный пул аккаунтов.

4. **[Реализовано] Безлимитный пин чатов в папках локально (Unlimited Pinned Chats in Folders)**:
   - В `window_peer_menu.cpp` вызов `PinnedLimitReached(controller, history, filterId)` обходит блокировку при `filterId != 0`.
   - В `Data::Session` методы `pinnedCanPin(filterId, history)` и `pinnedChatsLimit(filterId)` возвращают соответственно `true` и `10000`.
   - В `Data::PremiumLimits` снят порог `dialogFiltersChatsCurrent()` / `dialogFiltersChatsPremium()`, что позволяет закреплять неограниченное число диалогов внутри любых папок клиента.

5. **[Реализовано] Динамический индикатор скорости загрузки и скачивания файлов**:
   - В `Ui::FormatTextWithReadyAndTotal` интегрирован сглаженный расчёт скорости передачи данных ($\Delta\text{bytes} / \Delta\text{time}$) со скользящим окном замеров и автоматической очисткой завершённых задач.
   - Форматирование скорости: `X.X MB/s`, `X.X KB/s`, `X B/s` отображается рядом с прогрессом в сообщениях чатов, медиапросмотрщике и всплывающей панели загрузок `DownloadBar`.
   - Добавлена настройка переключения `AyuSettings::showTransferSpeed` в раздел `Настройки AyuGram -> Основные`.

6. **[Реализовано] Локальные заметки и теги к чатам и пользователям (Local User Notes & Tags)**:
   - Создан изолированный модуль `ayu/features/user_notes/` (`ayu_user_notes.h / .cpp`, `edit_user_note_box.h / .cpp`).
   - Данные (краткий тег, многострочная заметка, timestamp изменения) сохраняются в локальный JSON-файл клиента `tdata/ayu_user_notes.json` и никогда не передаются на серверы Telegram.
   - Отображение тегов `[тег]` рядом с именем диалога в шапке открытого чата (`HistoryView::TopBarWidget`) и в общем списке диалогов боковой панели (`Dialogs::Entry::chatListNameText`).
   - Блок локальной заметки с кнопкой быстрого редактирования встроен в секцию профиля пользователя / канала (`DetailsFiller::makeInfo`).
   - Добавлены пункты вызова «Добавить заметку» / «Редактировать заметку» в контекстные меню списка чатов, меню профиля и меню шапки чата (`window_peer_menu.cpp`, `ayu/ui/context_menu/context_menu.cpp`).
   - Реактивное обновление интерфейса через `rpl::producer<PeerId>` и инкремент локальных версий имени диалога.
